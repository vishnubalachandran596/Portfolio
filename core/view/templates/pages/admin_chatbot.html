The chatbot answers visitor questions using a RAG index built from the profile, skills, experience, education, courses, and articles currently in the database.

{{.ChunkCount}} chunk{{if ne .ChunkCount 1}}s{{end}} currently indexed.

This button waits for the rebuild to finish (usually under a minute) before confirming, since clicking it means you want the index current right now. Saving or deleting a course or article doesn't wait -- it just flags that something changed, and a background job picks that up within about 5 minutes and rebuilds then, so routine saves stay fast. Use this button for a first build, right after swapping the underlying AI model, after editing your profile/skills/experience/education (which don't have a save hook to set that flag), or whenever 5 minutes isn't fast enough.

A coding agent that edits content directly in Supabase can trigger the same rebuild via POST /api/chatbot/reindex with an Authorization: Bearer <CHATBOT_REINDEX_TOKEN> header, without an admin login.
