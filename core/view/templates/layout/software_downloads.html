Advanced / offline

Windows zip

Download TempleAccounts-windows.zip

Right-click the zip > Properties > tick Unblock > OK, then unzip the whole folder and open TempleAccounts.exe. If Windows Defender blocks it: Windows Security > Virus & threat protection > Protection history > Restore > Allow on device. Do not run it from inside the zip.

The same licence key works for both Windows downloads.

Mac (Apple Silicon)

Download TempleAccounts.app.zip

Unzip, move TempleAccounts.app to Applications. First open: System Settings > Privacy & Security > Open Anyway.

Linux (Ubuntu, Debian, Mint)

Download TempleAccounts-linux.deb

Install with: sudo apt install ./TempleAccounts-linux.deb, then open Temple Accounts from the app menu.
